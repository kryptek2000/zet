ZET Architecture

Rust + wgpu AI terminal — fast shell, agentic runtime, tiered safety. v0.1 draft.

Agent loop

  • • Propose → plan → gate → exec → verify
  • • 1 mutating lane + N read lanes
  • • Parent spawns children per worktree
  • • Recipes: repeatable, headless, shared

Safety first

  • • T0 auto → T3 type-to-confirm + sandbox
  • • Checkpoint every mutation, one-key undo
  • • Secrets redacted, audit per session
  • • Prod = dry-run plan by default

Perf gates

  • • <100ms cold, <3ms input, 120fps
  • • <80MB idle, cat-100k <0.9s
  • • Inline <50ms local, TTFT <2s
  • • CI-benched vs Ghostty / Warp
